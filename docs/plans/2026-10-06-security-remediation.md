# Security Remediation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the six security and availability findings F02, F03, F04, F08, F09, and F10 without relaxing tenant boundaries or changing the Fabric architecture.

**Architecture:** Keep Git edits as the source of durable coordination, use the existing Member and site reports for revocation and retirement, and constrain external network connections at the socket rather than only when a form is submitted. Retain Console, Warden, and site placement responsibilities; make admission checks reflect the intended destination.

**Tech Stack:** Go, `net/http`, Kubernetes/controller-runtime, Forgejo-backed `internal/fabric.Git.Edit`, SOPS/age, B2 native/S3 APIs, CloudNativePG, Go `testing`/`httptest`.
