> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make imported catalog workloads truthful and deployable, make the Console's live information and one-time actions reliable and accessible, and describe protection, catalog certification, and cooperative hosting without unsupported promises.

**Architecture:** Keep the embedded `cmd/console/web/index.html` page, its one escaped `html` rendering path, delegated actions, server APIs, and existing catalog importer; repair generic import/runtime contracts rather than adding app-specific exceptions.
